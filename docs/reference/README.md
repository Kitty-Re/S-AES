# 算法参考资料

本组以《密码编码学与网络安全——原理与实践》第 8 版附录 D“简化 AES”为算法依据，核对了状态排列、S 盒、列混淆矩阵和密钥扩展规则。课程资料入口见[作业要求](https://shimo.im/docs/zm1FlCxE3eYCQSSo)。

本组在仓库中保留教材名称、来源和算法参数，教材 PDF 使用课程提供的版本。本地对照时可将文件放在本目录，文件名为 `附录D 简化AES.pdf`；该文件通过忽略规则排除。

程序、自动测试和独立参考实现均可独立运行。本地存在教材副本时，验证脚本会记录其 SHA-256，便于核对资料版本；从仓库取得项目后即可直接安装依赖并运行实验。
