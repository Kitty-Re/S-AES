# 作业要求与范围记录

来源：[作业 2：S-AES 算法实现](https://shimo.im/docs/zm1FlCxE3eYCQSSo)，读取日期：2026-10-24。此文件整理与本项目有关的要求，原文以链接为准。

## 任务与标准

使用熟悉的语言编写 S-AES 加解密程序并提供 GUI；原作业要求三人组队。算法采用《密码编码学与网络安全——原理与实践》第 8 版附录 D。教材获取与本地放置方式见[参考资料说明](reference/README.md)。

| 条款 | 要求 | 项目对应位置 |
|---|---|---|
| 3.1 | 16 bit 数据、16 bit 密钥，交互式加解密 | 二进制页，`saes_app/core/cipher.py` |
| 3.2 | 同密钥、同明文与另一组得到相同密文，能够解密恢复 | 自检与交叉测试页、CSV 服务 |
| 3.3 | ASCII 字符串，以 2 Bytes 分组 | ASCII 文本页、文本服务 |
| 3.4.1 | 32 bit 密钥双重加密 | 双重与三重页 |
| 3.4.2 | 一组或多组已知明密文对，中间相遇寻找 K1+K2 | 中间相遇攻击页 |
| 3.4.3 | 32 bit 或 48 bit 密钥三重加密，任选一种 | 两种均实现，EEE 顺序在开发手册中定义 |
| 3.5 | CBC 长消息，生成并共享 16 bit IV；修改或替换密文后比较解密 | CBC 与篡改页 |
| 4 | 有意义命名、必要注释、函数和模块封装 | 核心 / 服务 / GUI 分层 |
| 5.2 | 源代码、各关测试结果、用户指南、开发手册与接口说明 | 根目录、`docs` 和 `docs/evidence` |

## 项目范围

1. 提供完整源代码、测试材料、用户指南、开发手册及通关说明。
2. 小组成员留空，不收录个人姓名、学号、邮箱或本机账号路径。
3. 使用用户转交的另一组数据完成交叉测试，原样保存数据包，记录本组加解密实际结果，不将原包的自检声明当成本组实测。
4. 仓库上传与课程线上提交分开处理，本项目不代填课程提交表。

原文记录的课程提交截止时间为 **2026-10-31 23:00**。
