# 界面设计说明

## 布局与视觉

界面采用深青色侧栏、浅灰绿背景、白色卡片及绿色主操作按钮。左侧保持六个功能入口固定，右侧每页独立滚动。导航编号是页面顺序，页面上方 LEVEL 标识才是课程关卡；第 4 关分为“多重加密”和“中间相遇”两个入口。

默认窗口 1180×900，最小 960×640。报告截图使用 1240×1000 展示更多信息，小窗口截图检验滚动与表单可达性。150% 与 200% 缩放分别在独立 Qt 进程中检查，避免同一进程修改缩放无效。

标题、说明、输入、主要操作、结果、过程表格依次排列。长二进制输入使用 Consolas，正文使用微软雅黑；系统未显示离屏字体目录时加载本机字体，不复制或分发字体文件。

## 页面职责

| 页面 | 主要内容 |
|---|---|
| 二进制加解密 | 16 位双输入、复制结果、轮密钥与过程表 |
| ASCII 文本 | 明密文双栏、编码格式、填充开关、原始字节视图 |
| 双重与三重 | 模式、宽度随模式提示、各级输入输出 |
| 中间相遇攻击 | 可编辑已知对、后台进度、完成状态、候选与全量导出 |
| CBC 与篡改 | 密钥与 IV、长消息、数据包、翻转 / 替换及差异表 |
| 自检与交叉测试 | 教材参数验证、可选枚举、CSV 交换与来源说明 |

## 交互与结果真实性

输入字段校验由服务完成，错误统一显示在页面顶部，避免弹窗打断连续实验。修改相关输入后清除结果；密文字节格式转换保留数据，转换失败恢复原格式。结果可选中复制，二进制结果另有专门复制按钮。

搜索与全分组自检使用 QThread。运行时禁用当前任务相关输入，保留取消操作；工作线程结束后才发布结果并恢复输入。后台服务不操作控件，界面不人为添加计算延时。取消后的部分结果明确标“未完成”，完整结果显示实际计算耗时。

候选、文本分组、CBC 对比及 CSV 界面限制展示前 200 行以保持响应；完整密文与候选导出仍保留全部数据。表格可独立滚动，单元格悬停可查看完整值。CSV 导入结论仅针对当前文件；组间实验暂缓状态直接写在页面中。

CBC 普通解密执行填充和文本解码；篡改比较独立使用原始分组，以观察非法填充或乱码情况下的差异。比较操作不会改写原密文。

## 复用与可访问性

卡片、表单、位串输入、文本输入、结果复制、表格与任务组件分别封装。标准 Qt 控件提供 Tab 焦点、上下导航、F2 单元格编辑、文本选择和系统缩放支持；焦点边框与错误文本可见，颜色不是区分完成 / 取消的唯一手段。

不额外制作位图素材，应用图标用 QPainter 绘制四个半字节方格，保持清晰缩放。源码入口见 `saes_app/ui/widgets.py`、`tasks.py` 和 `theme.py`。
